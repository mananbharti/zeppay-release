## Install safely

1. Download the APK and open it on your phone. Android will ask you to allow "install from this source" once.
2. **Keep Google Play Protect turned on** and let it scan the app when it offers to. ([What Play Protect does](https://support.google.com/android/answer/2812853?hl=en))
3. If Play Protect shows a genuine **harmful app / blocked** warning, **do not ignore it or install anyway.** Instead: note the exact warning text, and report it as a false positive using Google's [Play Protect appeal form](https://support.google.com/googleplay/android-developer/contact/protect) - ZepPay reads no SMS, uses no accessibility service and no device-admin rights, so a harmful verdict would be a false positive worth appealing.

ZepPay runs UPI payments over `*99#` (no internet needed). On Jio it uses the UPI 123PAY call. Your UPI PIN is only ever entered in your bank's own prompt.

iPhone? Use the web app: https://mananbharti.github.io/zeppay/ios/
